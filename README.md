# Intermodal Accessorial Invoice Audit

Validate intermodal storage, lifts, chassis, and terminal accessorials against event timelines and contract responsibility.

**Primary buyer:** Shippers, 3PLs, and intermodal marketing companies. **Evidence:** contracts, rail waybills, container events, appointments, free time, storage, lifts, chassis, drayage, invoices, disputes, and credits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Provider contract library
- Shipment container registry
- Rail event ingestion
- Terminal event timeline
- Appointment evidence
- Free-time calculation
- Storage charge audit
- Lift charge validation
- Chassis responsibility
- Flip split validation
- Drayage linkage
- Invoice recalculation
- Provider dispute package
- Credit reconciliation
- Terminal provider analytics

Run `./start.sh`, then open <http://127.0.0.1:4698>. API: `5698`.
